# Чудо-котёл

Браузерная игра на русском: три ингредиента создают монстрика, затем можно выбрать цвет, аксессуары, имя и познакомиться с ним. Два ингредиента одной стихии дают лесного, звёздного или огненного монстра; три разных стихии дают редкого чудика. Последний друг сохраняется в localStorage браузера.

## Запуск

Нужен Python 3. Из каталога проекта:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Зависимости устанавливать не требуется. `npm start` запускает тот же сервер. `npm run check` проверяет синтаксис JavaScript (Node.js 18+).

## Проверка игры

Нажмите «Начать колдовать», выберите три разных предмета (можно перетащить в котёл), создайте монстра, примерьте наряды, задайте имя и нажмите «Подружиться». Проверьте приветствие, танец, объятия, переодевание и восстановление друга после перезагрузки. Звук включается отдельно и использует синтез речи браузера; доступность русского голоса зависит от устройства. Без звука реплики видны в облачке. В браузерах с запретом локального хранилища игра работает без сохранения.

Шрифты Google Fonts необязательны: при отсутствии сети используются системные. Игра не требует аккаунта, ключей API или сервера данных.
